## 작업 목표 
엑셀 주문 데이터를 기준으로 월별 매출 HTML 대시보드를 생성하는 파이썬 코드를 만들어줘.
사용자는 엑셀 파일을 직접 첨부하지 않고, 파이썬 실행 시 파일 탐색기에서 엑셀 파일을 선택할 거야.

## INPUT 
엑셀 파일에는 주문데이터 시트가 있고, 헤더는 아래와 같아.

주문일자 / 주문월 / 주문번호 / 고객명 / 고객구분 / 지역 / 지점 / 담당자 / 상품군 / 상품명 / 수량 / 단가 / 매출금액 / 할인금액 / 순매출 / 주문상태 / 결제수단

주요 항목은 아래 값을 기준으로 해줘.

지점: 서울본점, 대전지점, 부산지점, 광주지점, 대구지점
결제수단: 현금영수증, 계좌이체, 간편결제, 카드
상품군: 전산용품, 사무용품, 생활용품, 비품, 소모품

## PROCESS 
- 파이썬 실행 시 파일 탐색기로 .xlsx 파일을 선택하게 해줘.
- 선택한 파일의 주문데이터 시트를 읽어와.
- 월 선택 필터는 전체와 데이터에 있는 모든 월을 자동으로 표시해줘.
- 월을 선택하면 KPI, 차트, 상세 테이블이 해당 월 기준으로 바뀌게 해줘.
- 단, 월별 순매출 추이(전체) 차트는 월 선택과 관계없이 전체 월 추이를 항상 보여줘.
- 주문 상세 데이터는 주문일자 기준 오름차순으로 정렬해줘.
- HTML 파일은 실행 파일 위치의 결과 폴더에 저장해줘.
- 결과 폴더가 없으면 자동으로 생성해줘.
- 파일명은 마지막 주문일자 기준으로 매출주문_분석_yymmdd.html 형식으로 저장해줘.
- 같은 파일명이 있으면 _1, _2처럼 번호를 붙여 덮어쓰지 않게 해줘.

## OUTPUT 
실행 가능한 파이썬 코드 1개를 작성해줘.

HTML 대시보드에는 아래 항목을 포함해줘.

KPI:
- 총매출
- 순매출
- 주문건수
- 평균 주문금액
- 취소율

차트:
- 월별 순매출 추이(전체): 선 차트
- 상품군별 매출 비중: 도넛 차트, 범례 오른쪽, 마우스 오버 시 합계 금액 표시
- 지점별 순매출: 세로막대 그래프
- 결제수단별 주문건수: 세로막대 그래프
- 담당자별 순매출: 세로막대 그래프
- 상품별 매출액 TOP 10: 세로막대 그래프

표:
- 주문 상세 데이터: 주문일자, 주문번호, 고객명, 지점, 담당자, 상품군, 상품명, 수량, 매출금액, 할인금액, 순매출, 주문상태, 결제수단이 주문일자 기준으로 오름차순 정렬되어 제시

차트 배치:
