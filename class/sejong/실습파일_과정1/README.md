## 구성 원칙

- 지점 4곳(서울강남점·대전둔산점·세종보람점·청주가경점), 상품 6종, 단가는 전부 공통자료 파일에서 그대로 가져와 모든 실습파일에 동일하게 적용
- 365 전용 함수(UNIQUE 등)는 어떤 파일에도 "작동하는 수식"으로 저장하지 않음 — 2016 이하에서 `_xlfn.UNIQUE` 오류로 깨지기 때문(안내 텍스트로만 제공)
- 05의 해독용 수식 3종, 06의 미션 정답 숫자는 강의교안 HTML에 인용된 값과 100% 일치하도록 먼저 파일을 만들고 거기서 실제 값을 뽑아 교안을 작성함
