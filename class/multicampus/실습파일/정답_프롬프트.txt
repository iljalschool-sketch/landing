■ 9. 08 파이썬 엑셀 다루기 실습 — 질문
------------------------------
## 목적
폴더 안에 있는 xls확장자를 xlsx로 변환한다.

## INPUT 
1. 파일은 한 폴더 안에 들어있음 
2. 폴더를 선택하면 그 안에 있는 xls파일만 자동으로 선택 

## PROCESS 
1. xls파일을 xlsx파일로 저장 

## OUTPUT 
1. 파일명은 원본이랑 동일하고 확장자만 다르게 저장 
2. 원본은 현재 폴더에 하위 폴더로 "원본"폴더를 만들고 그 위치로 이동 
3. xslx파일은 현재 폴더에 하위 폴더로 "xlsx"폴더를 만들고 그 위치로 저장


■ 10. 08 파이썬 엑셀 다루기 실습 — 같은 형식의 여러 엑셀 파일 취합하기
------------------------------
## 목적
폴더 안에 있는 엑셀 파일을 하나의 파일로 합친다.

## INPUT
 - 폴더를 선택하면 해당 폴더에 있는 모든 엑셀 파일 사용 
- 한 파일에 하나의 시트만 있음 
- 데이터의 구조는 동일함(모든 파일의 헤더가 동일) 

## PROCESS 
- 폴더 안의 모든 파일을 병합함 
- 거래일자, 거래처명, 제품명 순으로 오름차순 정렬 
- 수량, 단가(원), 공급가액(원), 부가세(원), 합계(원) 는 콤마스타일 적용 
- 1~3열은 열 너비를 14, 4~10열은 열너비를 10으로 변경 
- 헤더는 하늘색 적용 

## OUTPUT 
-병합된 파일은 2025_1분기_매출기록.xlsx로 저장


■ 11. 08 파이썬 엑셀 다루기 실습 — 항목별로 차트 만들기
------------------------------
## INPUT 
- 윈도우 탐색기로 파일 선택 
- 파일에 시트는 하나이고 1열에는 제품명이 그 이후 열에는 1월부터 12월까지 매출 건수가 입력되어있음 

## PROCESS 
- 각 제품별로 1월~12월의 판매건수를 세로 막대그래프로 생성 
- 막대그래프의 색상은 #B6D1E0 적용
- 제품 별로 매출 건수가 가장 높은 3개 항목은 #E33364 적용 
- 데이터 레이블에 콤마스타일 적용하여 추가 
- 모든 차트의 맥스값을 600으로 통일 

## OUTPUT - 파일명: {제품명}_매출차트.png 
- 저장위치: 현재 폴더에 "차트"폴더 추가 후 그 안에 저장 
- 생성된 모든 파일을 하나의 워드파일에 담아서 저장 워드파일 생성시 제목으로 "2025년 제품별 판매 건수 추이"라고 입력 각 항목별로 블릿으로 제품명을 입력하고 다음 줄에 차트를 삽입


■ 12. 08 파이썬 엑셀 다루기 실습 — 그래프 편집 요청하기
------------------------------
차트는 잘 생성되었는데 디자인이 마음에 들지 않아. 
차트에 다음의 디자인을 적용시켜줘.
* 차트 색상은 푸른색 계열로 왼쪽이 하늘색 오른쪽으로 갈수록 짙은 푸른색으로 적용
* 데이터레이블 추가(콤마스타일 적용)
* Max값을 1.2~1.3배해서 상단에 여백을 확보


■ 13. 08 파이썬 엑셀 다루기 실습 — 거래처별로 자료 만들기(차트 생성)
------------------------------
## INPUT 
- 윈도우 탐색기로 파일 선택 
- 선택된 파일의 거래일자, 거래처명, 합계(원) 사용 

## PROCESS 
1. 거래처명 별로 데이터를 나눠서 [거래처명]_yymmdd.xlsx로 각자 저장 
1-1. 헤더와 기타 서식은 그대로 유지되어야함.(파일 복사 후 필요 없는 행을 삭제하는 방식 사용) 
1-2. 시트명은 거래처명으로 변경 

2. 거래처명별로 월별 합계(월)의 합계를 세로 막대그래프로 생성 
2-1. "거래일자"는 엑셀의 날짜 형식임 
2-2. 막대그래프 색상: #28D390, #00B89B, #009B9B, #007F8E, #1A6277, #2F4858 적용 
2-3. 반드시 한글 글꼴 적용 
2-4. Y축 눈금값을 제거하고 데이터 레이블 추가(콤마스타일 적용) 
2-5. max값을 1.2배하여 상단에 여백 남기기 

3. 1번의 파일에 각각 생성된 차트 이미지를 추가 
3-1. 두번째 시트를 추가하고 이미지 삽입 
3-2. 시트명은 "[거래처명]_매출차트" 

## OUTPUT 
- 생성된 파일은 엑셀파일이 선택되었던 폴더에 "전송자료"폴더를 생성하고 그 안에 저장 
- 생성된 파일에 대해서 거래처명, 파일저장경로를 정리해서 "이메일전송자료.xlsx"파일로 저장


■ 14. 08 파이썬 엑셀 다루기 실습 — 월간 실적 보고서 취합하기
------------------------------
## 목적
월간 실적 보고서 엑셀파일들의 내용을 하나로 취합한다.

## INPUT
윈도우 탐색기로 취합할 월간 실적 보고서 엑셀 파일들을 선택한다
월간 실적 보고서 엑셀 파일은 시트가 하나가 있고 다음의 특성을 가짐
1. 헤더가 4행
2. 지점 열은 셀병합 되어있음
3. 지점별로 소계 행이 있음(3열까지 셀병합)
4. 마지막 행에는 전체 합계행이 있음(3열까지 셀병합)

## PROCESS
별도의 엑셀 파일을 열어서 선택한 모든 "월간 실적 보고서"의 내용을 취합함(어펜드)
지점이 공백인 경우 윗 행의 내용을 채워넣음
지점별 소계, 전체 합계 행은 삭제
현재 데이터의 오른쪽에 열을 추가(연도, 월, 원본파일)
연도에는 원본 파일명의 앞 4자리, 월에는 파일명의 _앞의 2자리(숫자로), 원본파일에는 데이터를 가지고 온 파일명을 입력
예시: 파일명이 "2026-01_월간실적보고서"인 경우 연: 2026, 월: 1, 원본파일: 2026-01_월간실적보고서.xlsx

## OUTPUT
선택된 파일과 같은 폴더에 1분기 실적 누적.xlsx파일 생성


■ 15. 08 파이썬 엑셀 다루기 실습 — 분기별 보고서(워드)만들기
------------------------------
## 목적
선택한 엑셀 파일의 내용을 분석하여 분기별 보고서(WORD)파일을 만든다.

## INPUT
윈도우 탐색기로 분석에 필요한 실적 누적 엑셀 파일을 선택한다.
파일에는 시트가 하나이고 다음과 같은 헤더를 갖는다.
지점 담당자 상품군 목표매출 실적매출 달성률 비고 연도 월 원본파일

## PROCESS
1. 월별로 목표매출, 실적매출, 달성률을 계산한 표 생성

2. 담당자들의 월별 실적매출의 합계를 분석하여
지점, 담당자, n월, n+1월, n+2월, 합계를 첫 행으로 하는 표를 생성한다
표의 하단에는 합계 행을 추가한다.
동일한 지점끼리 정렬하고 지점별로 담당자 이름을 가나다순으로 정렬한다.

3. 직원별 총 매출 차트
총 매출액이 높은 직원이 상단으로 오는 가로막대 그래프 생성
담당자(지점) 으로 계열명 설정
데이터 레이블을 콤마스타일로 적용
막대그래프는 남색

4. 상품군별 월별 실적매출의 합계를 분석하여
상품군, n월, n+1월, n+2월, 합계를 첫 행으로 하는 표를 생성한다

5. 상품군별 월간 실적 매출 차트
상품군을 계열로 하는 누적세로막대그래프 생성

## OUTPUT
첨부한 샘플파일의 서식과 동일한 양식의 워드 보고서 생성
파일명은 "yyyy년_n분기_영업실적보고서"

■ 18. 03 매출전표 캡쳐하기 — 매출전표 캡쳐하기
------------------------------
## 목적
엑셀파일에서 선택되어있는 데이터의 승인번호를 찾아서 PDF파일에서 캡쳐해서 저장한다.

## INPUT
윈도우 탐색기로 엑셀파일과 PDF파일을 선택
엑셀파일은 헤더가 2행이다.
PDF파일은 여러장이며 한 장에 매출전표가 2*2형태로 4개 들어있다.

## PROCESS
1. 엑셀 파일에 "증빙필요"열이 TRUE인 행의 "승인번호"를 PDF파일에서 찾는다.
2. 찾은 승인번호의 위치가 몇사분면인지 확인한다. 
3. 해당하는 사분면에 해당하는 이미지를 캡쳐한다
4. 파일명을 "거래일시"의 거래일자를 yymmdd형식으로 표시, 가맹점명 사용하여 yymmdd_가맹점명.png로 저장

## OUTPUT
실행파일의 하위 파일에 "증빙자료"폴더가 없으면 폴더를 생성하고 그 안에 저장

■ 25. 07 대시보드 만들기 — AI에게 일을 명확하게 시키기
------------------------------
## INPUT 
엑셀 파일에는 주문데이터 시트가 있고, 헤더는 아래와 같아.
```
**엑셀 파일의 헤더 입력**
```
주요 항목은 아래 값을 기준으로 해줘.
```
**고정된 항목이 있는 경우 하위 항목을 제시해 주는것이 레이아웃 잡는데 유리함**
지점: 서울본점, 대전지점, 부산지점, 광주지점, 대구지점
결제수단: 현금영수증, 계좌이체, 간편결제, 카드
상품군: 전산용품, 사무용품, 생활용품, 비품, 소모품
```

## PROCESS 
- 파이썬 실행 시 파일 탐색기로 .xlsx 파일을 선택하게 해줘.
- 선택한 파일의 주문데이터 시트를 읽어와.
- 월 선택 필터는 전체와 데이터에 있는 모든 월을 자동으로 표시해줘.
- 월을 선택하면 KPI, 차트, 상세 테이블이 해당 월 기준으로 바뀌게 해줘.
- 단, 월별 순매출 추이(전체) 차트는 월 선택과 관계없이 전체 월 추이를 항상 보여줘.
- HTML 파일은 실행 파일 위치의 결과 폴더에 저장해줘.
- 결과 폴더가 없으면 자동으로 생성해줘.
- 파일명은 마지막 주문일자 기준으로 매출주문_분석_yymmdd.html 형식으로 저장해줘.
- 같은 파일명이 있으면 _1, _2처럼 번호를 붙여 덮어쓰지 않게 해줘.

## OUTPUT 
실행 가능한 파이썬 코드 1개를 작성해줘.

## HTML 세부사항

HTML 대시보드에는 아래 항목을 포함해줘.

KPI:
** 중심으로 보고자 하는 내용(정확한 헤더명을 이용해서 계산 방법을 기재하면 더 좋음)
- 총매출
- 순매출
- 주문건수
- 평균 주문금액
- 취소율

차트:
** 보여주고 싶은 차트가 있는 경우 차트명과 차트 종류, 기타 요청사항 기재 **
- 월별 순매출 추이(전체): 선 차트
- 상품군별 매출 비중: 도넛 차트, 범례 오른쪽, 마우스 오버 시 합계 금액 표시
- 지점별 순매출: 세로막대 그래프

- 담당자별 순매출: 가로막대 그래프
- 상품별 매출액 TOP 10: 가로막대 그래프

표:
** 제시하고 싶은 표가 있다면 헤더명과 정렬 방법 제시**
