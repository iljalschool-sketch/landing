# 로직플로우 홈페이지

[logicflow.ai.kr](https://logicflow.ai.kr) · GitHub Pages로 호스팅됩니다.

**이 문서만 보면 홈페이지 내용을 혼자 수정할 수 있습니다.** 코드는 건드릴 필요 없습니다.

- **강의 이력·누적 지표** → `강의이력.xlsx` (엑셀, 저장소 바깥)
- **그 밖의 내용** → `data/` 폴더의 JSON 파일

---

## 1. 강의할 때마다 하는 기록 (엑셀)

**`강의이력.xlsx` 한 파일만 관리하면 됩니다.**

위치: `OneDrive\Files\10_LogicFlow\강의이력.xlsx`
(`landing` 폴더 **바로 바깥**입니다. 홈페이지 저장소 안에 두면 에이전시명·교육대상 같은 내부 기록까지 인터넷에 공개되기 때문입니다.)

강의를 할 때마다 `강의이력` 시트에 **한 줄씩** 추가하세요. 노란 칸이 필수입니다.

| 일자 | 강의명 | 표시기관명 | 교육대상 | 형태 | 교육시간 | 수강인원 | 구분 | 모집상태 | 홈페이지표시 |
|---|---|---|---|---|---|---|---|---|---|
| 2026-10-15 | AI활용 실무: 사무자동화 마스터 클래스 | 대구YMCA | 대성에너지 직무훈련과정 | 오프라인 | 8 | 24 | 기관·기업 | | Y |

저장한 뒤 Claude에게 **"강의이력 업데이트해줘"** 라고 말하면 끝입니다.
(직접 하시려면: `python tools/build_lectures.py`)

### 한 번 입력하면 세 군데에 쓰입니다

| 쓰이는 곳 | 처리 방식 |
|---|---|
| **강의 이력 목록** | 같은 강의명+기관은 **한 줄로 합쳐지고** `5회` 배지가 붙습니다 |
| **누적 지표** | 모든 회차를 **합산**합니다 (수강생·횟수·시간·기관 수) |
| **사업 영역의 「수강 가능 교육」** | `모집상태`가 채워진 과정만 자동으로 올라갑니다 |

그래서 대구YMCA 건을 5번 했으면 **5줄을 입력**하세요. 목록은 한 줄로 깔끔하게 나오고,
누적 인원은 5회분이 전부 더해집니다.

### 모집상태 — 홈페이지 맨 위에 올릴지 정합니다

| 값 | 뜻 | 화면 |
|---|---|---|
| (비워둠) | 지난 강의 | `구분`에 따라 아래쪽 목록으로 |
| `신청가능` | 지금 신청할 수 있음 | **「수강 신청 가능」 맨 위** + 링크 + 「신청하러 가기 →」 |
| `오픈예정` | 일정 확정, 링크는 아직 | **「수강 신청 가능」 맨 위** + `개설 예정` 배지 (링크 없음) |

### 모집마감일 — 끝난 과정이 저절로 내려갑니다

**공개 과정의 마지막 교육일을 적어두세요.** 그날이 지나면 「수강 신청 가능」에서
자동으로 내려갑니다. 예를 들어 올해 마지막 교육이 11월 20일이면 `2026-11-20`을
적어둡니다. 11월 21일부터는 신청 영역에 안 나옵니다.

내년 과정이 열리면 **마감일만 내년 날짜로 바꾸면** 다시 올라옵니다.

> 마감일을 비워두면 직접 모집상태를 지울 때까지 계속 노출됩니다.
> 끝난 과정이 "신청 가능"으로 남는 건 가장 치명적인 사고이니 꼭 적어두세요.

### 변환할 때 자동으로 잡아주는 것

- `신청가능`인데 신청링크가 없음
- 모집상태가 있는데 모집마감일이 없음
- 모집마감일이 지나 자동으로 내려간 과정
- 모집 중인데 `홈페이지표시 = N`

### 형태 — 온라인 과정은 꼭 표시하세요

`오프라인`(기본) / `온라인`(실시간) / `VOD`(녹화) 중에서 고릅니다.
온라인·VOD는 **지역 제약이 없어 홈페이지에서 가장 반응이 좋은 상품**이라 배지로 눈에 띄게 표시됩니다.

### 엑셀 쓸 때 알아둘 것

- **`집계` 시트**는 수식입니다. 입력하는 대로 합계가 보입니다. 직접 고치지 마세요.
- **`홈페이지표시`를 `N`** 으로 하면 목록에는 안 나오지만 **누적 인원에는 포함**됩니다.
  (비공개 사내 교육 등에 쓰세요.)
- **헤더(4행) 이름을 바꾸면** 자동 반영이 멈춥니다.
- **비고가 `예시`로 시작하는 줄**은 집계·반영에서 제외됩니다.
- 열 순서는 바꿔도 됩니다 (헤더 이름으로 찾습니다).

## 2. JSON을 직접 고쳐야 하는 작업

### 강의 이력 추가하기 (엑셀 대신 직접 넣을 때)

> 평소에는 위의 엑셀을 쓰세요. `build_lectures.py`를 실행하면
> 아래에서 직접 고친 `groups` 내용은 **엑셀 기준으로 덮어쓰기** 됩니다.

`data/lectures.json` 을 열고, `기관·기업 강의` 그룹의 `items` **맨 위**에 한 줄 추가합니다.

```json
{ "title": "생성형 AI 활용 업무혁신 과정", "client": "한국전력공사" },
```

- `title` : 강의명 (필수)
- `client` : **화면에 표시할 이름** (선택) — 아래 표기 원칙 참고
- `target` : 실제 교육 대상 (선택) — 예: `대성에너지 직무훈련과정`
- `agency` : 경유한 에이전시 (선택) — **화면에 안 나오는 내부 기록용**
- `year` : 연도 (선택, 넣으면 옆에 작게 표시됨)
- `url` : 신청 페이지 주소 (선택, 넣으면 클릭 가능해짐)

> 쉼표 위치를 조심하세요. 마지막 항목 뒤에는 쉼표를 붙이지 않습니다.

#### 기관명 표기 원칙

| 상황 | 표기 | 예시 |
|---|---|---|
| 들으면 아는 곳 | 실명 | `KISTI`, `멀티캠퍼스`, `NH투자증권`, `대구YMCA` |
| 에이전시 경유 + 최종 교육처가 알 만한 곳 | 최종 교육처만 (에이전시는 `agency`에) | `대성에너지` |
| 둘 다 무명 | 이름 대신 업종·구분 | `제조업 재직자 과정`, `지역 중소기업 직무교육` |

모르는 에이전시 이름은 신뢰도를 올리지 못하고 목록만 흐립니다.
이름을 빼는 것은 숨기는 게 아니라 **읽는 사람에게 의미 있는 정보로 바꾸는 것**이며,
고객사 동의 문제도 함께 피할 수 있습니다.

```json
{
  "title": "AI 활용 사무자동화",
  "client": "제조업 재직자 과정",
  "agency": "○○교육컨설팅"
}
```

### 누적 수강생 수 바꾸기 — 엑셀이 자동으로 계산합니다

**직접 세지 않아도 됩니다.** 1번의 엑셀에 입력하면
누적 수강생·강의 횟수·교육시간·기관 수가 전부 자동 계산됩니다.

`data/stats.json`에서 `source`가 붙은 항목은 **엑셀이 채우므로 직접 고치지 마세요.**
`source`가 없는 항목만 손으로 수정하면 됩니다.

### 활동사진 추가하기

1. 사진 파일 이름을 `20261120_부산시_01.jpg` 형식(`날짜_지역_번호`)으로 바꿉니다.
2. `홍보/활동사진_모자이크` 폴더에 넣습니다.
3. 아래 명령을 실행합니다.

```bash
python tools/build_gallery.py
```

리사이즈·EXIF 제거·`data/gallery.json` 갱신이 한 번에 됩니다.
그 다음 `data/gallery.json` 에서 `caption`을 실제 기관명으로 고치면 더 좋습니다.

> **사진은 반드시 모자이크 처리된 것만 올리세요.** 수강생 얼굴이 식별되면 초상권 문제가 됩니다.

### 유튜브 영상 추가하기

`data/videos.json` 에서 해당 시리즈의 `videos` 배열 맨 아래에 추가합니다.

```json
{ "id": "dErLAh4kDxI", "title": "영상 제목" }
```

`id`는 유튜브 주소 `watch?v=` **뒤에 오는 값**입니다.

## 3. 수정한 내용을 사이트에 반영하기

```bash
git add . && git commit -m "강의 이력 추가" && git push
```

푸시하면 GitHub Pages가 **1~2분 안에** 자동 반영합니다.
브라우저에 바로 안 보이면 `Ctrl + F5` 로 새로고침하세요.

> GitHub 웹사이트에서 파일을 직접 편집해도 됩니다. 저장소 → 파일 클릭 → 연필 아이콘 →
> 수정 → Commit changes. **휴대폰에서도 가능합니다.**

## 4. 폴더 구조

```
10_LogicFlow/
├── 강의이력.xlsx               ★ 강의할 때마다 여기에 기록
│                               (저장소 바깥 — 인터넷에 공개되지 않습니다)
└── landing/                    ← 여기부터 홈페이지 저장소. 전부 공개됩니다
    ├── index.html              레이아웃 껍데기 (내용 없음)
    ├── data/                   ← ★ 홈페이지 내용
    │   ├── site.json           소개 영상 · 아키텍트 소개 · 연락처
    │   ├── stats.json          누적 지표 (엑셀이 자동으로 채움)
    │   ├── courses.json        사업 영역 · 수강 가능 교육 (엑셀이 자동으로 채움)
    │   ├── lectures.json       강의 이력 (엑셀이 자동으로 채움)
    │   ├── automation.json     자동화 개발 이력
    │   ├── education.json      학력
    │   ├── videos.json         유튜브 영상 목록
    │   └── gallery.json        활동사진 목록
    ├── assets/
    │   ├── brand.css           ★ 브랜드 색상·폰트 (한 곳에서 관리)
    │   └── render.js           JSON을 읽어 화면을 그리는 코드
    ├── images/
    │   ├── brand/              로고 · 파비콘 · OG 이미지 · 프로필
    │   └── gallery/            활동사진 (thumb/ = 격자용 축소본)
    ├── tools/
    │   ├── build_lectures.py   엑셀 → lectures · stats · courses.json
    │   ├── build_gallery.py    활동사진 리사이즈 · EXIF 제거
    │   ├── build_brand.py      로고 · 파비콘 · OG 이미지 · 프로필 생성
    │   ├── recalc_excel.py     엑셀 수식 재계산 · 오류 검사
    │   └── make_lecture_workbook.py   엑셀 양식 생성 (최초 1회용)
    ├── class/                  수강생 전용 페이지
    └── report/                 리포팅 솔루션 소개 페이지
```

## 6. 수정 전 로컬에서 확인하기

```bash
python -m http.server 8765 -d .
```

브라우저에서 `http://localhost:8765` 로 접속합니다.
화면이 비어 보이면 **F12 → Console** 에 JSON 오류가 찍혀 있습니다
(대부분 쉼표를 빠뜨렸거나 더 붙인 경우입니다).

JSON 문법만 미리 검사하려면:

```bash
python -c "import json,glob; [json.load(open(f,encoding='utf-8')) for f in glob.glob('data/*.json')]; print('이상 없음')"
```

## 7. 주의사항

- `data/*.json` 에서 `_주석`, `_항목형식` 으로 시작하는 키는 설명용입니다. 지우지 마세요.
- 페이지 제목·설명·OG 태그·히어로 문구는 검색엔진 노출을 위해 `index.html` 에 직접 적혀 있습니다.
  이 부분은 JSON이 아니라 HTML을 고쳐야 합니다.
- `CNAME` 파일은 도메인 연결 설정입니다. 지우면 `logicflow.ai.kr` 접속이 끊깁니다.
